# Matt Soucoup

A personal blog and portfolio built with Hugo and hosted on GitHub Pages. The site uses a small custom theme in `layouts/` and `static/`; no theme submodule is required to build it.

## Local Development

```bash
# Install Hugo (macOS)
brew install hugo

# Clone the repository
git clone https://github.com/codemillmatt/soucoup.com.git

# Run local server
cd soucoup.com
hugo server -D
```

Visit `http://localhost:1313` to preview.

## Writing

Create a new post in `content/posts/`:

```bash
hugo new posts/my-new-post.md
```

Or manually create a markdown file:

```markdown
---
title: "Your Post Title"
date: 2026-01-22
draft: false
tags: ["ai", "tutorial"]
categories: ["how-to"]
---

Your content here...
```

## Deployment

The site automatically deploys when you push to `main`:

1. Write your post in `content/posts/`
2. Open a pull request
3. Merge to `main`
4. GitHub Actions builds and deploys to GitHub Pages

## Enabling GitHub Pages

1. Go to repository **Settings** → **Pages**
2. Under **Build and deployment**, select **GitHub Actions**
3. Push to `main` to trigger the first deploy

The home page, writing archive, post template, search index, and RSS feed are generated by Hugo. The `index.json` output powers the site search. Code blocks use Hugo's syntax highlighter and get copy buttons in the browser.

## Subscribe

The RSS feed is live at `/index.xml`. An email newsletter is not connected yet; update `content/subscribe.md` once a provider and signup URL are ready.

## Design

The homepage starts with the newest post. Put `<!--more-->` after its opening paragraphs to choose where the homepage excerpt ends. Shared styles live in `static/css/site.css`; templates are in `layouts/`.
